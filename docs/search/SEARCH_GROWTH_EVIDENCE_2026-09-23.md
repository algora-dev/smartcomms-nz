# SmartComms NZ — Search Growth & Evidence Record

**Prepared:** 23 September 2026  
**Basis:** owner-supplied Google Search Console exports reviewed in this project plus public-source research performed for this pass.

## Search Console interpretation

The site is young. Early Search Console data shows Google beginning to associate SmartComms most strongly with school bell, paging, announcement, intercom and emergency/lockdown intents. Many important URLs were recently reported as **Discovered – currently not indexed** with no crawl yet, so low positions or narrow query coverage are not by themselves evidence that those pages require a rewrite.

### First-page priorities for strengthening

1. `/systems/school-bell-announcements`
2. `/systems/emergency-lockdown`
3. `/systems/ip-paging-pa`
4. `/systems/ip-intercom`

This pass strengthens those existing pages rather than creating thin new query variants.

## Evidence-diversity rule

Technical product capability should normally be supported by first-party manufacturer documentation.

NZ-local implementation/supply evidence should use legitimate local sources and should not depend disproportionately on SmartComms' preferred partners.

Current public examples introduced/used in this growth pass include:
- Edwards — Three Kings Primary;
- Pacific AV — Ormiston Junior College;
- Edwards — Richmond Road Primary;
- Audio Connect — Sanitarium Auckland distribution centre;
- G&S Technologies — Summerset St Johns;
- Sektor NZ — current 2N IP Verso 2.0 listing.

These sources have different roles. A project case supports a local implementation statement; a reseller listing supports local product/channel availability; neither automatically proves market share or universal suitability.

## What this release does not claim

- It does not claim measured search volume for every phrase added.
- It does not guarantee rankings, AI citations or traffic growth.
- It does not infer a commercial/referral relationship from editorial coverage.
- It does not treat historical 2N audio installations as proof that discontinued Net Audio products are a current new-build platform.
- It does not treat an integrator case study as independent verification of a manufacturer-wide performance claim.

## Measurement plan

After deployment, compare Search Console at roughly weekly intervals while the site is still young:
- indexed URL count;
- discovered-not-indexed count;
- impressions/clicks by page;
- unique queries;
- query clusters for bells, emergency, paging and intercom;
- average position by landing page;
- Google generative-AI feature impressions where supplied.

Do not react to ordinary crawl/index lag with mass rewriting. Strengthen a page when evidence shows a real answer/content/internal-link gap, not merely because it has not yet ranked.
